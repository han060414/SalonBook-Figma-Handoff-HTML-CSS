# SalonBook — Figma Handoff HTML5/CSS3

Website Trang chủ SalonBook phục vụ mục 4.3 trong báo cáo **Chuẩn hóa quy trình Handoff từ Figma đến HTML/CSS**.

## Cấu trúc

- `index.html` — Trang chủ theo HTML5 semantic.
- `style.css` — Design Tokens qua CSS Custom Properties, Flexbox, Grid và Responsive.
- `assets/` — 3 ảnh salon thật và hình minh họa Hero do nhóm cung cấp.

## Xem website

Mở `index.html` trong trình duyệt, hoặc chạy với VS Code Live Server. Không cần cài dependencies.

## Kích thước tham chiếu

- Desktop: 1440px (container tối đa 1150px)
- Tablet: 768px
- Mobile: 390px (có xử lý màn hình nhỏ từ 320px)
